# Business Model

## Business architecture

Continuity uses a product-led infrastructure model:

| Layer | Continuity |
|---|---|
| Free adoption | Open-source CLI and local MCP |
| Developer platform | API, SDKs, console, CI templates |
| Ecosystem | Provider Migration Capsules and MCP clients |
| Authority | ChangeBench research and reproducible benchmarks |
| Self-serve revenue | Free, Pro, Max, and Scale |
| Enterprise conversion | Private deployment, policy, evidence, support, and Book a Call |
| Trust | Open formats, local execution, docs, security material, and changelog |

The structure is informed by Supermemory's combination of open source, local
operation, API/MCP entry points, research, usage plans, private deployments,
and contact-led enterprise sales. Continuity must retain original product,
copy, design, benchmarks, and claims.

## Customer ladder

### Individual developer

Entry points:

- open-source repository;
- CLI package;
- MCP configuration;
- technical documentation;
- ChangeBench.

Upgrade triggers:

- more private projects;
- more verified repairs;
- scheduled monitoring;
- team collaboration.

### Team

Value:

- shared projects and evidence;
- CI policies;
- usage controls;
- centralized provider capsule subscriptions;
- consistent verification.

### API or SDK provider

Value:

- ecosystem-wide counterfactual simulation;
- one official migration capsule;
- reduced repeated support work;
- adoption and compatibility visibility;
- release policies.

### Enterprise

Value:

- private deployment;
- SSO and policy;
- dedicated capacity;
- evidence and audit support;
- customer-operated models;
- disconnected operation;
- service commitments and forward-deployed support.

Enterprise pricing is never displayed. All enterprise calls to action say
**Book a Call**.

## Public plans

| Plan | Public presentation |
|---|---|
| Free | $0 with limited projects, simulations, and repairs |
| Pro | $29/month for individual developers |
| Max | $129/month for power users and small teams |
| Scale | $499/month for production teams and API startups |
| Enterprise | Book a Call |

Metering is based on bounded verified-repair credits and project limits, not
unbounded model tokens. Plans include hard spend controls. Customer-operated
models reduce hosted compute use.

## Distribution loops

### Developer loop

CLI or MCP install → useful repository finding → verified repair → team invite
→ paid plan.

### Provider loop

Provider publishes capsule → customers install or subscribe → provider receives
aggregate compatibility → more customers request official capsules.

### Research loop

ChangeBench publishes reproducible evaluation → developers compare results →
install CLI → contribute fixtures and outcomes → benchmark quality improves.

### Enterprise loop

Team adoption → security review → private deployment → broader project coverage
→ provider participation.

## Sales motion

Self-serve plans require no sales call. Enterprise uses a Cal.com **Book a
Call** action for:

- private deployment;
- custom capacity;
- policy and identity requirements;
- evidence requirements;
- support and service commitments.

No public enterprise price, price range, or starting price is permitted.

## Business metrics

- active protected projects;
- successful simulations;
- verified repair acceptance;
- individual-to-team conversion;
- paid-plan retention;
- provider capsules published and consumed;
- time saved per completed migration;
- enterprise calls booked and qualified;
- gross margin per verified repair.

Source code and private telemetry are never a resale product.
