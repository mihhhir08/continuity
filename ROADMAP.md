# Roadmap

## Milestone 1 — Repository foundation

Deliver:

- authoritative PRD;
- architecture, business, landing-page, security, and source documentation;
- decision, status, and handoff records;
- agent instructions and contribution templates;
- private GitHub repository and milestone issues.

Acceptance:

- A new session can identify the product, architecture, current state, and next
  task without this conversation.
- All documents agree with `PRD.md`.
- Enterprise has no public numeric price.
- Public product surfaces are CLI, MCP, API, and console; CI templates are
  integrations.
- No credentials or unsupported claims are committed.

## Milestone 2 — Marketing site

Deliver:

- multi-route marketing site;
- synthetic Counterfactual Change Network demonstration;
- self-serve pricing;
- Enterprise Book a Call;
- configurable Cal.com modal;
- original social-preview image;
- production deployment.

Acceptance:

- Responsive and WCAG 2.2 AA.
- No copied assets or language.
- No fabricated proof.
- Enterprise card contains no price.
- Configured and unconfigured Cal.com behavior is truthful.

## Milestone 3 — Local product demonstration

Deliver:

- Rust engine;
- CLI;
- local MCP server;
- TypeScript and Python fixtures;
- one OpenAPI change simulation;
- deterministic repair;
- customer-owned verification;
- offline-verifiable evidence.

Acceptance:

- Clean installation reproduces the demonstration.
- Source remains local.
- Failed checks cannot produce verified evidence.
- CLI and MCP return consistent structured results.
- Write-capable operations require authorization.

## Milestone 4 — Hosted business layer

Deliver:

- hosted API;
- console and authentication;
- usage tracking and billing;
- native CI templates;
- capsule publishing;
- durable jobs;
- ChangeBench.

Acceptance:

- API mutations are idempotent.
- Local work continues during hosted unavailability.
- Usage and spend controls are enforceable.
- Benchmark results are reproducible.

## Milestone 5 — Enterprise and ecosystem

Deliver:

- SSO and policy;
- dedicated and self-hosted deployments;
- audit and evidence exports;
- Java and Go;
- GraphQL and gRPC;
- provider capsule distribution;
- expanded MCP and CI integrations.

Acceptance:

- Same API contract across hosted and private deployments.
- Disconnected workflow verifies capsules and evidence offline.
- Tenant and policy isolation pass adversarial tests.

## Validation targets

Targets are hypotheses until supported by real usage:

- 30 days after developer release: 100 installations, 20 active projects, 10
  genuine migrations, and 3 design partners.
- 90 days: 1,000 protected projects, 5 paying teams, and 2 provider pilots.
- 6 months: 10 providers and 10,000 protected projects, with revenue goals
  updated from measured conversion.
